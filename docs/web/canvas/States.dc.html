WHY NO "TRY AGAIN"

With a single provider, retry is a wall dressed as a door. Each screen offers the one action that can actually change the outcome — and for a refusal, that is a person, not a button.

WHY THE STATUS CODES ARE ON THE MOCKUP

A denial that returns 200 has already happened on this desk once. The code is part of the design, not an implementation detail, so it is specified here where it can be reviewed.
