PUBLIC SURFACE — THE SYSTEM

Same tokens as the desk. Different scale, different density.

The public pages inherit the desk's palette and typefaces so the product a stranger is shown is the product they get. What does not carry over is the density: the desk is a 12–13px instrument for someone who already trusts it, and this is 17px prose for someone who does not.

label / mono 11 / .16em EYEBROWS, STATUS, COLUMN HEADS

Mono is not decoration here. It marks anything the machine asserted — a symbol, a price, a timestamp, a state, a status code — which is the same rule the desk already follows. Prose is never mono.

NOTE: the artboards on this canvas pull Geist from Google's font CDN, because that is the only font host the canvas sandbox permits. The shipped pages self-host it — next/font already does this for the desk, so the files exist. Do not copy the artboard's font link into a page.

WHAT THESE PAGES DO NOT LOAD

No client JavaScript

Nothing on the public pages moves, so nothing needs to hydrate. The argument renders on the first paint or it does not render.

No third-party requests

No analytics, no tag manager, and the fonts are self-hosted rather than pulled from Google's CDN — a page arguing "we take three things from you" cannot open by handing a visitor's IP to someone else before they have agreed to anything.

No cookie banner

Because there is nothing to consent to: the only cookie is the session, and it is set after you sign in, not before.

These are a routing decision as much as a design one. /_next/static/ is already public, but /_next/image and /_next/data are deliberately not — so a public page using next/image, or a favicon served from /, renders broken to a stranger and perfectly to everyone on this desk. Every mark on these pages is inline SVG, which sidesteps the whole class.
