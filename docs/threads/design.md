**Six product decisions are blocking, not optional** — audit §11. Item 1 in
particular gates most of Phase 2: **is the Google Sheet permanent or a migration
artefact?** The Sheet/Auto duality is the largest source of visual complexity in
the product — the conflict apparatus, the two Momentum Cycle sections, the
verbatim Sheet block, the `Confirmation` column. If human review is permanent,
that machinery should be designed properly as a review workflow. If the Sheet is
going away, most of it should be deleted rather than polished. Ask before
building.

## Working rules

- **Terminology is trader-facing.** Labels that describe engine internals get
  rejected — `LATCH` was removed for exactly this. Say it in the language of the
  stock, not the pipeline.
- **Verify on the live desk**, not fixtures. The one Phase 1 defect that reached
  production was invisible to local fixtures.
- **Commit each approved piece separately** and report the hash.
- Gate before every commit: `npm test`, `npm run lint`, `npm run typecheck`,
  `npm run build`.
